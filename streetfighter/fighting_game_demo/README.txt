DR. POMBO vs MR. BOOMBASTIC - DEMO

1) Instale Python 3.11+.
2) No terminal desta pasta:
   pip install pygame
3) Rode:
   python main.py

CONTROLES
P1: A/D andar, W pular, S defender, J soco, K chute, L especial
P2: Setas esquerda/direita, cima, baixo, NUM1 soco, NUM2 chute, NUM3 especial

Os sprites usados aqui foram recortados da folha de sprites gerada durante a conversa.
Depois, para colocar os seus personagens definitivos, substitua os PNGs nas pastas:
assets/dr_pombo/
assets/mr_boombastic/

O jogo foi escrito para manter combate e arte separados, facilitando a troca futura por sprites próprios.
